# Описание проекта

Реализован планировщик с базовой функциональностью:
- создание, удаление, редактирование, выполнение задачи
- получение списка задач
- указание регулярности выполнения задач
- поиск задач

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.
Директория `web` содержит файлы фронтенда.

# Реализованные задания со звездочкой

- Возможность определять извне порт при запуске сервера через переменную окружения TODO_PORT
- Определение пути к базе данных через переменную окружения TODO_DBFILE
- Поддержка вычисления следующих дат (для повторяющихся задач) в случае недель и месяцев
- Поиск задачи по дате и подстроке
- Dockerfile для создания образа

# Инструкция по запуску локально

Проект компилируется командой `go build -o main.exe` 
После этого запускайте программу командой `./main.exe` (Linux/Mac) или `main.exe` (Windows).

Используется файл с переменными окружения `.env`.
- `TODO_PORT` — порт для запуска сервера (по умолчанию 7540)
- `TODO_DBFILE` — путь к файлу базы данных (по умолчанию `./scheduler.db`)
- `TODO_WEB_DIR` - путь к файлам фронтенда (по умолчанию `./web`)

Запуск приложения в браузере: [http://localhost:7540/](http://localhost:7540/)

# Инструкция по запуску тестов

Тесты запускаются после запуска программы (см. инструкцию по запуску локально).
Настройки в файле `./tests/config.json`:
- Port = 7540
- DBFile = "../scheduler.db"
- FullNextDate = true
- Search = true
- Token = ``

FullNextDate устанавливаем **True**, если нужно включить поддержку вычисления следующих дат для повторяющихся задач в случае недель и месяцев.
Search устанавливаем **True**, если нужно включить поддержку поиска задач по дате и подстроке.

Запуск тестов:
- `go test -run ^TestApp$ ./tests`
- `go test -run ^TestDB$ ./tests`
- `go test -run ^TestNextDate$ ./tests`
- `go test -run ^TestAddTask$ ./tests`
- `go test -run ^TestTasks$ ./tests`
- `go test -run ^TestTask$ ./tests`
- `go test -run ^TestEditTask$ ./tests`
- `go test -run ^TestDone$ ./tests`
- `go test -run ^TestDelTask$ ./tests`
- для запуска всех тестов `go test ./tests`

# Инструкция по сборке в docker

Образ создается под linux с родительской папкой `/app`. Приложение комилируется в файл `./todo-app`.

Команда сборки образа `docker build --tag todo-app:v1 .`

Команда запуска контейнера 
``` 
docker run --rm -d \
  --name todo-app \
  -p 7540:7540 \
  -v D:/Yandex.Disk/project/GO/dev/go_final_project/scheduler.db:/app/scheduler.db \
  todo-app:v1 
```

При монтировании файла *scheduler.db* необходимо в команде заменить абсолютный путь к базе данных хоста на тот, что действителен для вашего проекта.
